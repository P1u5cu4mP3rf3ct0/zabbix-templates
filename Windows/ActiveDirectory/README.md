# Windows Active Directory — Templates (ActiveDirectory / AD / Domain Controller)

This directory groups templates related to Active Directory (Domain Controllers). To improve discoverability for international users, there are two language-specific subfolders:

- ENG/ — English templates and documentation
- ESP/ — Spanish templates and documentation

Place language-specific template YAMLs inside the corresponding subfolder. The ENG README and the top-level README are in English for wider visibility. The ESP README contains Spanish guidance and notes.
